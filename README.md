# James Platt

I'm studying Electrical & Electronic Engineering at the University of Manchester and will be joining Alpine F1 in Electronics Design in July 2027.

I'm interested in hardware design, embedded systems, and understanding what the software is actually doing to the hardware. Most of my work involves C/C++, CAN networks, and increasingly, FPGAs.

Previously Electronics Lead for Manchester Stinger Motorsports during the 2025–26 Formula Student season, working across the IC and EV platforms.

## Selected Work
- [CAN Sensor Node](https://github.com/ManchesterStingerMotorsports/johnson-node) — reusable ESP32-S3 sensor node with interchangeable sensor boards and FreeRTOS tasks for sampling and CAN transmission.
- [Electronic Gear Shifter](https://github.com/ManchesterStingerMotorsports/gear-shifter) — closed-loop actuator control using CAN state and absolute encoder feedback, with checks before each shift.
- [MSM_CAN](https://james-platt.com/building-a-can-bus-library) — ESP32 CAN abstraction layer and API.
- [Luciferin](https://james-platt.com/luciferin-pt2) — custom motor controller for Team Firefly's Greenpower car, covering power electronics and control firmware.
- [Icarus](https://github.com/Trovix/Icarus) — paper-only convergence trader for equivalent binary markets on Kalshi and Polymarket, built in C++ and Python.

## Technical Areas
- Hardware design and power electronics
- Embedded C/C++ (ESP32, FreeRTOS)
- CAN bus systems (network design, tooling)
- Safety-critical embedded systems (shutdown circuitry, actuator control)
- Digital control systems
